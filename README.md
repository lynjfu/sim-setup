# sim-setup

The guided setup page for the simulation explorer: **https://carolynjfu.com/sim-setup/**

Describe a simulation of organizational learning in five questions, download one prompt with your answers already in it, give it to any AI assistant, and paste the `model.js` it writes into the [online explorer](https://carolynjfu.com/sim-explorer/) with **Load your own model**. Only you can see the model you load: it runs in your browser and is not uploaded.

This repository holds only the page (`index.html`). The prompt it hands out (`start/prompt.js`) and the example animation (`start/example.gif`) are built and served from [lynjfu/sim-explorer](https://github.com/lynjfu/sim-explorer), which also has the full instructions, the explorer page and a worked example.
